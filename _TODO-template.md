## Binary Artifacts Reference

All signed documents, receipts, and regulatory confirmations should be stored in `09-binary-artifacts/` following this structure:

```
09-binary-artifacts/
├── 01-formation/           # Signed bylaws, resolutions, incorporation docs
├── 02-constating-documents/ # Signed shareholder agreements, policies
├── 03-registers/           # Physical register copies (if maintained)
├── 04-meetings-and-resolutions/
│   ├── board/YYYY/         # Signed board minutes and resolutions
│   └── shareholders/YYYY/  # Signed shareholder minutes and resolutions
├── 05-capitalization/      # Signed share certificates, subscription agreements
├── 06-regulatory-filings/  # CRA confirmations, provincial registrations
├── 07-finance-and-tax/     # Bank statements, tax filings, financial statements
├── 08-commercial-and-ip/   # Signed contracts, IP assignments
└── receipts/YYYY/          # Business expense receipts
```

See [09-binary-artifacts/README.md](./09-binary-artifacts/README.md) for naming conventions and Git LFS setup.
